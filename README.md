ОПЕРАЦІЙНІ СИСТЕМИ РЕАЛЬНОГО ЧАСУ ТА 32 БІТНІ МК

Лабораторна робота №1:  Технологія програмування портів вводу-виводу загального
призначення на основі прототипу операційної системи нескінченного циклу опитування

Обладнання: STM32H743VIT6, CubeMX, STM32CubeIDE.

Мета: Ознайомитися з принципами програмування GPIO STM32F411 у режимі реального часу на основі нескінченного циклу опитування.

Завдання до лабораторної роботи:

Варіант X: Реалізувати неблокуючу передачу 4 байт (0xDE, 0xAD, 0xBE, 0xEF) по SPI (Master) з періодом рівно 5 секунд за допомогою таймера TIM1.
Керування лінією NSS здійснити програмно через обробники переривань («0» перед стартом, «1» після завершення).

💡 Загальний опис функціоналу

Програма реалізує асинхронну (неблокуючу) передачу даних по інтерфейсу SPI1, де ініціатором транзакції виступає базовий таймер TIM1. 
Головний цикл while(1) залишається абсолютно порожнім, що дозволяє мікроконтролеру виконувати інші задачі або перебувати в режимі енергозбереження.

Ключові механізми роботи:
- Робота таймера (TIM1): Таймер тактується від внутрішньої шини з частотою f = 64 МГц. Для отримання періоду в 5 секунд (0.2 Гц) використано наступні налаштування:
1) Prescaler (PSC) = 31999.
2) Дільник частоти: 64 000 000 / (31999 + 1) = 2000 Гц. Таймер робить один "тік" кожні 0.5 мс.
3) Period / AutoReloadRegister (ARR) = 9999. Таймер рахує до 9999, що займає рівно: 2000 Гц / (9999 + 1) = 0.2 Гц (5 секунд).
4) Запуск транзакції (TIM1 Callback):Кожні 5 секунд спрацьовує переривання таймера і викликається функція HAL_TIM_PeriodElapsedCallback.
У ній: Лінія SPI1_NSS примусово переводиться в низький рівень (RESET), активуючи ведений пристрій.
5) Викликається функція HAL_SPI_Transmit_IT, яка запускає апаратну передачу масиву даних (0xDEADBEEF) у фоновому режимі та виходить.
6) Завершення транзакції (SPI Tx Callback):Коли всі 4 байти фізично виштовхнуті з регістру зсуву мікроконтролера, апаратура SPI генерує власне переривання, що викликає
7) HAL_SPI_TxCpltCallback. У цій функції лінія SPI1_NSS повертається у високий рівень (SET), сигналізуючи логічному аналізатору (або веденому пристрою) про успішне завершення пакету.

⚙️ Схема підключення
 STM32H743 (Master) → Логічний аналізатор:
- PA4 (SPI1_NSS / GPIO_Output) → CH3 (Enable/CS).
- PA5 (SPI1_SCK) → CH2 (Clock).
- PA6 (SPI1_MISO) → CH1 (MISO).
- PA7 (SPI1_MOSI) → CH0 (MOSI).
- GND (Земля мікроконтролера) → GND (Земля логічного аналізатора).
